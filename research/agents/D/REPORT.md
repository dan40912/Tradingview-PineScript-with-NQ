# D 報告：把各代理的候選組成「投資組合」（books）

研究用途，不是投資建議。只用 2024-01～2025-12 的資料，**沒有讀 2026**（`include_holdout` 一律 False）。全部損益都由共用引擎 `sim.run_signals` 算，呼叫各代理凍結的候選函式，沒有改任何參數。

## 一句話結論
- 凍結 4 本組合（`portfolios.py`，sha256 `2697b290…`）。在 2024–25 這兩年，**4 本都在所有指標上贏過 1 口 NQ 的 I2 v1**：總獲利、最大回撤、報酬／回撤、日 Sharpe、最差一天、最差一個月都比較好。
- 最穩的是 **D1 保守組**：只做 A3_C3，8 口 MNQ。總獲利 +$18.7k（I2 是 +$12.1k），回撤 −$2.9k（I2 是 −$8.2k）。
- 最賺的是 **D3 等風險組**和 **D4 積極組**：兩年約 +$68k，回撤約 −$5k。但約 4 成獲利來自 ES 那條腿，而 ES 的進場是被汙染的，2025H2 又特別好。拿掉 ES 仍然贏 I2，只是差距小很多。
- **這不是樣本外結果。** 候選是在這兩年裡挑出來的，2025H2 也被後面的階段看過。組合的數字只能當「上限」，要靠 2026 holdout（E 階段）和之後的前進紀錄來確認。

## 3. 衝突規則（事先定好，全部只用當下已知的資訊）
| 規則 | 內容 |
|---|---|
| A | 一本組合最多只有一個 I2 家族袖子（由組合定義保證） |
| B | 新訊號如果和**任何**未平倉部位方向相反（NQ 或 ES 都算，兩個市場走勢同向），就跳過新訊號 |
| C | 未平倉停損風險合計 ≤ 2R。新訊號放不下就以 0.1 口為單位縮小，縮到 0 就跳過 |

同一分鐘同時進場時，按組合定義的順序處理（I2 家族 → TE → ES）。實際上這些規則很少觸發：D3 兩年只動到 8 筆，D4 動到 8 筆（`out_contrib.csv`）。拿掉規則，結果幾乎一樣（第 7 節）。

## 9. 誠實評估
1. **這些都是樣本內數字。** 每個袖子都是各代理在 2024–25 挑出來的。I2 的進場本身是前人看過 2024–2026 資料才選的；ES 進場（5 點分箱）也被前人看過到 2026-10；TE 部分汙染；ORB15 的想法來自看過 validation 的線索。組合的數字一定會高估未來。
2. **最可信的是 D1。** 它只靠一個想法（A3 的 POC 目標＋60 點停損＋沒進展就出場），validation 也最乾淨（A3 的 81 個鄰近參數格全正）。但它和 I2 v1 逐筆比較，95% 區間仍然包含 0。它主要的好處是風險：最差一天 −$998，I2 是 −$2,948。
3. **D2 是最平衡的選擇。** 回撤和 D1 差不多（−$3.0k），獲利約 2 倍。27 組權重擾動全部贏 I2。就算拿掉 ES，或讓 ES 在 2025H2 空手，仍然是 I2 的 2～3 倍獲利、不到一半的回撤。
4. **D3、D4 的數字最漂亮，但最依賴 ES。** ES 腿約佔 4～5 成獲利，其中一半來自 2025H2。1 年 bootstrap 的 95% 最壞回撤約 −$9k，已經超過 I2 的歷史回撤。實際下單前，建議至少等 ES 腿在 2026 holdout 和之後的前進紀錄裡證明自己。
5. D4 的 ORB15_TP110 是 C1 三個候選裡最不被看好的（validation 非 I2 日每筆為負）。它在組合裡佔比不大（每筆只有 1–3 MNQ），D4 的表現主要還是 TE＋ES。
6. 執行面：
   - A3 有一半以上的目標只有 20～25 點，限價單不一定成交。
   - ES 停損只有 15 點，快市容易滑價。
   - D3、D4 要同時看 NQ 和 ES，每天最多 3 筆。
   - 微型成本用大口的 1/10，算是保守的假設。
7. **建議 E 階段的順序**：D1 → D2 → D3／D4。用 `BOOKS[name](include_holdout=True)` 跑 2026，**不要再改權重或規則**。如果 holdout 裡 ES 腿虧錢，就退回 D1 或 D2。
