## 3. 資料怎麼做的

### 3.1 主要資料：期貨平台歷史資料

- 從 主要資料源 逐合約下載 1 分鐘成交資料（Last），2024 年 3 月合約到 2026 年 12 月合約（H24 ～ Z26），每個商品共 12 個合約。
- 同一合約有好幾份下載檔時，以第一份為主，其他檔只補第一份沒有的分鐘。
- 下載檔的最後一根如果是匯出時還沒走完的半根，就改用其他檔裡完整的那根。
- 不同下載檔對同一分鐘的數值偶爾不一樣，共 25 分鐘，差異只有成交量 1–2 口，或夜盤開盤價差 0.5–1.25 點。這些都以第一份為準。

### 3.2 換月規則

- **每季在四巫日（3、6、9、12 月的第三個星期五）當週的星期二換到下一季合約。**
- 從那個星期二交易日的開盤（美東前一天 18:00）起，整天都用新合約：
  - 美國夏令時間：台北 **06:00** 換月
  - 美國冬令時間：台北 **07:00** 換月，實際上只有 12 月
- 換月發生在開盤那一刻，不會出現同一天上午用舊約、下午用新約，當沖比較乾淨。

### 3.3 剔除休市時段的棒

主要資料源 的原始資料，在市場休市的時間也有零星的 K 棒，共 412 根：

- 週末 353 根
- 每日維護時段（美東 17:00–18:00）57 根
- 假日收盤後 2 根

這些棒的開高低收都一樣，同一個價格和成交量會在休市期間重複出現，不是實際成交，所以全部剔除。

### 3.4 用第二資料源的資料補斷線（`source = B`）

主要資料源 的資料偶爾會斷線幾分鐘。

- 幾乎每次都是 NQ 和 ES 在同一分鐘一起斷，而且多半發生在行情劇烈的日子。
- 斷線最長的一次是 2026-07-17，美股盤中斷了 68 分鐘。
- 斷線的時候市場是有交易的，第二資料源的資料在這些分鐘都有成交紀錄。

補的方式：

1. 斷線的分鐘，用第二資料源裡**有實際成交**的棒補上。成交量為 0 的補齊棒一律不用。
2. **斷線旁邊那一根也換掉**。斷線前後那一根，主要資料源 常常只記到一部分成交（例如成交量 446 口，實際是 3,208 口），或混進了錯誤時間的成交。只要跟第二資料源不一致，就改用第二資料源。

結果：

| | NQ | ES |
|---|---|---|
| 補上斷線的分鐘 | 139 根 | 138 根 |
| 換掉斷線旁的棒 | 30 根 | 32 根 |
| `source = B` 合計 | 169 根（0.017%） | 170 根（0.017%） |

補棒前做過的檢查：

- 兩份資料都有的分鐘，OHLCV 完全一致的比例是 ES 98.8%、NQ 96.9%。差異大多是同一筆成交被歸到相鄰的分鐘，價差多半在 1 點以內。
- 補上的棒全部通過檢查：高低關係正確、價格在 0.25 跳動單位上、成交量大於 0、成交量和前後時段相當。
- 補完之後，接縫處的價格跳動都在當時前後一小時的正常範圍內。

**限制**：第二資料源和 主要資料源 不是同一個資料源，無法百分之百保證補上的棒和交易所的紀錄完全一致。如果不想用，可以用 `df[df.source == "A"]` 排除。不過排除後，這些分鐘就會變成缺口。

### 3.5 不造棒、不填零、不調價

- 補完之後還是沒有的分鐘，第二資料源也沒有，判斷是那一分鐘沒有人成交，**不會自己造一根**（第 7 節）。
- 價格完全不調整。

## 4. `day_quality`：每日品質分類

| 值 | 意思 | NQ | ES |
|---|---|---|---|
| `normal` | 正常交易日，美股盤中（RTH）完整 | 696 天 | 696 天 |
| `holiday_short` | 美國假日提早收盤 | 27 天 | 25 天 |
| `rth_gap` | 美股盤中有空分鐘。只有 ES 的 2025-02-17、2025-11-27 兩個假日短盤各少 1 分鐘，判斷是那一分鐘沒有成交 | 0 天 | 2 天 |
| `exclude` | **建議整天排除**。只有 2025-11-28，CME 全市場停盤約 10 小時（第 8 節） | 1 天 | 1 天 |

一天同時符合好幾類時，依 `exclude` → `rth_gap` → `holiday_short` → `normal` 的順序取第一個。ES 那兩天其實也是假日短盤，但歸在 `rth_gap`。

```python
import pandas as pd
df = pd.read_csv("NQ_1m_continuous_20240102-20261019.csv")

df = df[df.day_quality == "normal"]                        # 最嚴格：只用正常交易日
df = df[df.day_quality.isin(["normal", "holiday_short"])]  # 保留假日短盤
df = df[df.day_quality != "exclude"]                       # 最寬鬆：只排除 2025-11-28

rth = df[df.is_rth == 1]                                   # 只取美股盤中
```

### 7.2 補不到的分鐘（推測沒有成交）

某一分鐘沒有人成交，主檔就沒有那一列：沒有時間、沒有價格，也沒有成交量為 0 的棒。所以每天的 K 棒數不一定剛好是 1380 根。

- NQ 97 分鐘、ES 285 分鐘。幾乎都是單獨 1 分鐘（共 359 段），最長 3 分鐘，大多在亞洲時段（台北早上到下午）冷清的時候。
- **美股盤中只有 ES 的 2 分鐘**，都在假日短盤：2025-02-17（總統日，台北 02-18 01:18）、2025-11-27（感恩節，台北 11-28 01:36）。這兩天的 `day_quality` 是 `rth_gap`。
- 如果你的程式需要固定的時間格線，請自己補平盤棒：開高低收都等於上一根收盤，成交量為 0。

## 9. 使用注意事項

1. **至少排除 `day_quality == "exclude"`**（2025-11-28）。
2. **不要跨過換月計算指標。** 換月那一根會出現兩個合約之間的價差，NQ 約 210–310 點、ES 約 50–75 點，那不是行情。遇到 `is_contract_switch = 1` 就重新暖機，或者依 `contract` 分開計算。
3. **K 棒數量不固定**，見第 7.2 節。
4. **時間都是開棒時間。** 有些平台用收棒時間標 K 棒，跟其他資料比對時請注意差 1 分鐘。
5. **用 `trade_date` 分日，不要用台北日期分日**，否則一個交易日會被切成兩天。
6. 只有 OHLCV，沒有買賣價（bid/ask）、未平倉量、tick 資料。
