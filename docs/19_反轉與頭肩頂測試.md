# 抓反轉：頭肩頂／頭肩底、衝太遠後跌破 VWAP（2026-11-04）

## 起因：11/4
- 開盤 28,430.25（VAH 28,390 上方 40 點、前日範圍內、ES 同向）→ 10:15 衝到 28,969（+540）→ 11:05 跌到 28,481。
- 組合 D、I2 v1 **沒有訊號**：價格到 10:59 都沒有連續 2 根 5 分K 回到價值區；開在前日範圍內，順勢規則不適用。
- **前高空（只顯示、不是規則）09:35 做空 28,416.25，09:37 止損 −$2,948**：開盤 2 分鐘就衝上去。
- 事後看，10:15 的高點是標準的頭肩頂：左肩 28,868.50（09:45）、頭 28,969（10:15）、右肩 28,839.75（10:35），頸線 28,690～28,737.50，10:40 收 28,694 跌破。

## 1. 頭肩頂／頭肩底（`research/hs_pattern.py`）
規則（測試前定好）：5 分K 轉折點（左右各 k 根）；三個連續波段高點 左肩 < 頭 > 右肩，頭比兩肩高 ≥ 0.2×（頭 − 頸線），兩肩差 ≤ 0.5×（頭 − 頸線）；右肩確認後 5 分K 收破頸線 → 下一分鐘進場；SL＝右肩外 5 點（上限 150 點）；TP＝1R／2R／等幅；10:00 後、14:00 前進場；15:49 平倉。參數：k 1／2、頸線（近的低點／較低的低點）、目標 3 種、背景過濾（頭要在 VAH 和前日高之外）有／無 → 24 組。

| 型態 | 24 組裡全期每筆為正 | 三年都正 | 每筆中位數 |
|---|---:|---:|---:|
| **頭肩頂（做空）** | **0 組** | 0 組 | **−$178** |
| 頭肩頂，停損上限放寬到 250 點 | 1 組 | 0 組 | −$177 |
| 頭肩底（做多） | 14 組 | 少數 | +$8（每年正負來回） |

- 11/4 的頭肩頂在停損上限 150 點時不會進場（右肩外 5 點離進場 152 點）；上限放寬到 250 點會在 10:45 空 28,693、11:05 止盈 +$2,987。**今天剛好是會賺的那一天，但歷史上平均是虧的。**

## 2. 衝太遠後跌破（站回）VWAP（`research/exhaustion.py`）
規則：盤中高點比 VAH 高 ≥ X 倍區寬、而且在前日高之上，之後第一次 5 分K 收在 VWAP 之下 → 做空（底部反過來：低點比 VAL 低 ≥ X 倍、在前日低之下，之後收回 VWAP 之上 → 做多）；SL＝最近 30 分鐘極值外 5 點（上限 200）；TP＝1R／2R／回到價值區邊緣。

| | 結果 |
|---|---|
| 頂部做空（9 組） | 沒有一組三年都正；2026 年全部為負 |
| **底部做多、1 倍區寬（3 組）** | **NQ 三年都正**：1R +$163／+$302／+$59；2R +$165／+$214／+$314；回到 VAL +$254／+$175／+$108 |
| 同上，ES | 2024、2025 為正，**2026 為負**（−$322～−$392） |
| 同上，NQ 2026-10 起 | 7 筆，全部組合為負 |
| 底部做多、2～3 倍區寬 | 大多為負 |
| 11/4 | 沒觸發（30 分鐘內的高點就是頭部，停損要 280 點） |

「底部做多、1 倍區寬」只能列為**待驗證的假設**（只記錄、不交易），狀態和 docs/14 的 VWAP 發現一樣。

## 3. 為什麼抓頂這麼難
- NQ 2024–2026 一路上漲，做空的規則幾乎都比做多差（I2 做空每筆 +$115 vs 做多 +$249；突破共振做空 +$5 vs 做多 +$188）。
- 頭肩頂在事後很明顯，但事前同樣的形狀很多是假的：右肩之後再創新高、或跌破頸線後又拉回。
- 研究裡唯一有優勢的「反轉」是 I2：等價格**真的回到價值區**才進場，而不是猜頂部。

## 4. 建議
1. **不要用頭肩頂、目視的頂部去放空**。
2. **前高空、前低多建議預設關閉**：它們只是顯示，但看起來像訊號；11/4 開盤 2 分鐘就止損 −$2,948。
3. **每一筆真實交易都記下用的是哪條規則**，才能分辨虧在規則、還是虧在規則以外的判斷。
4. 新想法先寫成規則、在歷史和 ES 上測過，再用小口數前進測試。
