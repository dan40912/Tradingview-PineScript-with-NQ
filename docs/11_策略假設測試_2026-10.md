# 策略假設測試：用 2026-10 當測試期（2026-10-31）

## 一句話
測了 **944 種單一策略、401 種組合**。依照事先寫好的選擇規則，最好的是 **組合 D：I2（ES 同向）＋順勢突破**。2024-01～2026-09 每筆 +$395、最大回撤 $5,251、33 個月只有 4 個月虧，在 ES 上也成立。2026-10 只有 3 筆，合計 +$158，**樣本太少，不能當證據**。

現在的指標如果照著全部做（I2＋前高空＋前低多），2026-10-01～19 虧 $7,792，換到 ES 上也是虧的，**不建議交易參考點**。

## 1. 方法

| 項目 | 內容 |
|---|---|
| 資料 | `data/NQ_1m_continuous_20240102-20261019.csv.gz`、ES 同期（ES 價格 ×3.7 換成 NQ 等值點數） |
| 程式驗證 | 重算 I2 v1，和 `backtest/i2_v1_trades.csv` **159／159 筆一致**（進場時間、損益） |
| 成本 | 每筆 $48（1 口 NQ）；另外測每邊多滑 2 點（每筆再扣 $80） |
| 開發期 | 2024、2025：**兩年都要每筆為正**，合計至少 30 筆 |
| 驗證期 | 2026-01～09：每筆要為正 |
| 排名 | 通過的策略依「總獲利 ÷ 最大回撤」排名（越高＝賺得多、風險小） |
| 測試期 | **2026-10-01～19**（13 個交易日，選完才看）。10/20 之後沒有 1 分K 資料 |
| 組合規則 | 同時只持 1 筆、每天最多 3 筆、連 2 筆虧損或當日虧 $3,000 就停 |

> 為什麼不直接挑「10 月最賺」：10 月只有 13 天，每個策略 0～7 筆。挑 10 月最賺的，等於挑運氣最好的（見第 4 節）。

## 5. 建議的策略：組合 D（每條都附 TP／SL）

### 規則 1：I2（ES 同向）
| | 內容 |
|---|---|
| 方向 | NQ 09:30 開在 VAH 之上 → 只做空；開在 VAL 之下 → 只做多 |
| **ES 確認** | ES 09:30 也開在 **ES 自己的前日價值區**外、同一邊（回測用約 1.35 ES 點一格、70%） |
| 進場 | 連續 2 根 5 分K 收回 NQ 價值區 → 下一分鐘開盤；**最晚 10:59**；09:58–10:02 不進場 |
| **TP** | 進場價 **±55 點** |
| **SL** | 進場價 **∓145 點** |
| 出場 | **15:49** 還沒結束就平倉（不過夜） |

### 規則 2：順勢突破（IB 30 分）
| | 內容 |
|---|---|
| 條件 | NQ 開在價值區外，**而且**開在前日高低範圍外 |
| 確認 | 09:30–10:00 沒有 5 分K 收回價值區；之後只要收回就作廢 |
| 進場 | 10:04 起，開在 VAH 上方的日子 5 分K 收在 **IB 高點之上** → 做多；開在 VAL 下方的日子收在 **IB 低點之下** → 做空；下一分鐘開盤；最晚 12:00 |
| **SL** | **IB 中點**，距離最少 30、最多 80 點 |
| **TP** | **2 倍 SL 距離** |
| 保本 | 浮盈達 1 倍 SL 距離後，停損移到進場價（回撤從 $7,084 降到 $5,677） |
| 出場 | **12:29** 還沒碰到就平倉 |

### 風控
- 同時只持 1 筆；每天最多 3 筆；連 2 筆虧損或當日虧 $3,000 就停。
- 前進測試用 **MNQ**。規則 1 單筆最多虧 145 點（NQ 約 $2,948／MNQ 約 $300），規則 2 最多 80 點（NQ 約 $1,648／MNQ 約 $170）。

### 備選
- **不想看 ES**：用組合 A（I2 改良＋順勢 30）。回撤 $7,840，ES 每筆 +$121。
- **最重視跨市場一致**：用組合 E（順勢改成 IB 60 分、SL 20–60、2R、15:49 出場）。ES 每筆 +$276。

## 6. 風險與限制（一定要讀）
1. **選擇偏差**：測了 1,345 種，第一名的成績一定被運氣灌水。家族中位數比較接近實際：I2 每筆約 +$310、順勢 IB30／12:29 約 +$306。**規劃時建議把每筆獲利打 5 折、回撤乘 2**：D 約每筆 +$200、回撤約 $10,000、每月約 6.5 筆。
2. **ES 2026 年是負的**：D 在 ES 上 2026 年每筆 −$83，代表 2026 年 NQ 的好成績有一部分是 NQ 特有的大波動。
3. **ES 同向過濾在研究文件 06（H3）是「不通過」**：當時是 11:30 截止＋12:29 出場（文件寫 2024 每筆 +$14，我重算是 +$55）。這次是和「11:00 截止＋15:49 出場」一起才變好，屬於組合效果，可能是找出來的。
4. **10 月只有 13 個交易日**，10/20 之後的 1 分K 沒有資料（Yahoo 被環境的網路設定擋住）。
5. 1 分K 回測：同一分鐘同時碰到 TP 和 SL 一律算 SL；沒有考慮跳空穿過停損的滑價（另外測了每邊 2 點）。
6. 以上規則**都還沒做前進測試**。要上線，應該照 `08_驗收流程.md` 的方式另外登記、從登記日起算。
