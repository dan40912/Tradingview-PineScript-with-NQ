# NQ 紙上交易練習（POC）

研究用途，不是投資建議。

線上版：https://claude.ai/artifact/4f93vk7TgqJht33iHoJ6JL（只有擁有者能開，分享請用頁面的 Share 選單）

## 流程
1. **盤前**：隨機抽一天（日期收盤後才揭曉），停在 09:25。看波動倍數、前日價值區、前日高低、夜盤高低、前 3 日高低，依「每筆最多虧多少」算建議口數（波動 ≥ 2 倍自動減半），勾完三個確認才能開始。
2. **回放下單**：逐分鐘回放（1×～60×、+1／+5／+15 分、跳到下一個訊號）。v18 訊號出現時自動暫停：計畫內的點可以「照訊號下單」（+55／−145、12:29 平倉），灰點、藍點只標示不做。下單一律下一根開盤成交。虧一筆就鎖住今天（可在設定關掉）。
3. **收盤檢討**：揭曉日期，列出你的單、每筆是否符合計畫（不是計畫內訊號、時段外、口數過大、止損比 145 寬）、v18 當天所有點的結果，以及「照計畫做」的損益。
4. **存進紀錄**：寫心得後存檔；紀錄頁統計你的合計、照計畫的合計、差距、守規則的天數。存在 Claude 帳號（只有自己看得到），無法使用時存在瀏覽器。

## 檔案
| 檔案 | 用途 |
|---|---|
| `NQ紙上交易練習.html` | 頁面 |
| `engine.js` | 撮合引擎（頁面和回測共用）：先檢查止損再檢查止盈、時間到用收盤價、MNQ 每點 $2、每口 $4.8 |
| `days.json` | 隨機 120 天（種子 20261126；40 天波動 ≥ 1.8 倍），每天 07:00～16:00 的 1 分K、價位、v18 訊號 |
| `build_days.py` | 產生 `days.json`（需要 `research/trend_filter/README.md` 說明的合併資料和 v18 模擬結果） |
| `selftest.js` | 自我回測：引擎 vs v18 模擬器 |
| `e2e_test.js` | 瀏覽器端到端測試（Playwright） |

## 自我回測結果
- `node selftest.js`：120 天中圖內的 72 筆計畫內訊號，進場價 72/72、出場時間和損益 72/72 和 v18 模擬器一致，合計都是 +$43,754（1 口 NQ）。
- `node e2e_test.js`：在瀏覽器裡勾選、開始、跳到計畫內訊號、照訊號下單、結束、存檔；頁面損益和 v18 一致，手機寬度 400px 沒有橫向捲動，沒有錯誤。
